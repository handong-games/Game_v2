# Death Only Preview Sample

This folder contains temporary sample content for `com.uitoolkit.timeline`.

Run the menu item:

`UIToolkit Timeline > Samples > Create Death Only Preview Sample`

The menu creates three death-motion timeline assets under `Generated/`:

- `SoftSink_Timeline`
- `SnapSink_Timeline`
- `TiltSink_Timeline`

The menu opens the first timeline in the Timeline Asset Editor and selects all three generated timelines so you can compare them quickly.

Delete `Assets/UIToolkitTimelineSamples/DeathOnlyPreview` to remove this sample.
